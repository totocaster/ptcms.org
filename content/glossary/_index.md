# Glossary

<dl class="glossary-list">
<dt>Plaintext Tasks</dt>
<dd>A strict plain-text task format with headings, checklist states, notes, metadata lines, indentation-based subtasks, and an optional archive region. See <a href="/tasks/">Plaintext Tasks</a> for the current spec and version history.</dd>

<dt>plaintext files</dt>
<dd>Human-readable documents in Markdown or .txt.</dd>

<dt>Corpus</dt>
<dd>A folder of open files (your knowledge base/archive) that serves as the system of record.</dd>

<dt>frontmatter</dt>
<dd>Lightweight metadata at the top of a Markdown file (e.g., YAML).</dd>

<dt>sidecar / metadata file</dt>
<dd>A tiny <code>.json</code>/<code>.yaml</code> file placed next to a <code>.txt</code> note when metadata is needed.</dd>

<dt>tools</dt>
<dd>Editors, CLIs, indexers, and agents that operate on the corpus without owning it.</dd>

<dt>previewable writes</dt>
<dd>A workflow where tools generate human-auditable change previews before applying writes.</dd>

<dt>provenance trail</dt>
<dd>A simple history/log explaining why changes were applied, not only what changed.</dd>

<dt>AI / agent-aware</dt>
<dd>A tool exposing open, automatable interfaces (e.g., CLI, MCP, stdio, HTTP) for safe scripted/agent use.</dd>

<dt>browsing &amp; searching</dt>
<dd>Exploration and retrieval through indexers, embeddings, and link graphs.</dd>

</dl>
