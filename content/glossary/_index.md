---
title: "Glossary"
description: "Key terms used across the Plaintext Commons."
---

- **Plaintext files** — Human-readable documents in **Markdown or .txt**.
- **Corpus** — A folder of open files (your knowledge base/archive) that serves as the system of record.
- **Front matter** — Lightweight metadata at the top of a Markdown file (e.g., YAML).
- **Adjacent metadata file** — A tiny `.json`/`.yaml` file placed next to a `.txt` note when metadata is needed.
- **Tools** — Editors, CLIs, indexers, and agents that operate on the corpus without owning it.
- **Previewable writes** — A workflow where tools generate human-auditable change previews before applying writes.
- **Provenance trail** — A simple history/log explaining why changes were applied, not only what changed.
- **AI/agent-aware** — A tool exposing open, automatable interfaces (e.g., CLI/MCP/stdio/HTTP) for safe scripted/agent use.
- **Browsing & searching** — Exploration and retrieval through indexers, embeddings, and link graphs.
- **No exports. No migrations.** — The folder is the platform; the files are the protocol.
