# Formats

Plaintext Commons favors formats that remain understandable in any editor, survive tool churn, and can be rewritten with small, reviewable patches.

This section collects format families that keep the file as the source of truth while giving apps and agents enough structure to parse, present, and update content safely.

Use a family page to understand the format. Use a versioned URL when you need a stable reference.
